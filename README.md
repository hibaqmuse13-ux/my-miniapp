# 🚀 ApexInvest - Institutional Crypto Yield & Telegram Web App

ApexInvest is a high-yield institutional cryptocurrency investment platform integrated with a Telegram Bot and a secure WebApp interface.

## 🌟 Features
- **Secure Crypto Vault:** Supports USDT (TRC20, BEP20, ERC20) and USDC deposits and withdrawals.
- **Automated Yield Plans:** High-yield daily ROI tiers ranging from 5-day sprints to 15-day VIP max plans.
- **Telegram Bot Integration:** Instant admin notifications for deposits/withdrawals with interactive inline approval buttons.
- **SQLite Database:** Real-time persistence for users, balances, and transaction history.

## 🛠️ Tech Stack
- **Backend:** Python, Flask, SQLite
- **Bot Framework:** `python-telegram-bot`
- **Frontend:** HTML5, Tailwind CSS, JavaScript, Telegram Web App SDK

## 🚀 Deployment (Render / GitHub)
1. Set the Start Command on Render to: `python app.py`
2. Add your environment variables or configure your Telegram Bot Token directly in the script.
